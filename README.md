# Portfolio — Noé Goncalves de Veiga

Portfolio personnel : étudiant en BUT3 Informatique à l'IUT de Villetaneuse
(Université Sorbonne Paris Nord), en recherche d'alternance pour 2026-2027.

## Structure du projet

- `index.html` — Page unique du portfolio (parcours, réalisations, compétences, formation, contact)
- `style.css` — Feuille de style complète (thème sombre, responsive design)
- `script.js` — Menu mobile (burger), navigation active au défilement, effet machine à écrire et apparitions au scroll
- `bilan-sae-supervision.pdf` — Bilan réflexif pour le projet de supervision musicale
- `bilan-sae-analyse.pdf` — Bilan réflexif pour la SAÉ d'analyse de données
- `img/` — Captures d'écran et aperçus des projets

## Lancer en local

Ouvrir directement `index.html` dans un navigateur, ou lancer un serveur local :

```bash
python3 -m http.server 8000
```

puis aller sur http://localhost:8000

## Déploiement

Site 100 % statique (aucune dépendance à installer) : déployable tel quel
sur GitHub Pages, Netlify ou Vercel.
